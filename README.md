# Домашнє завдання: зроби свого Telegram-бота

Треба обрати один із трьох варіантів і створити простого, але завершеного бота.

## Рекомендована структура проекту
```text
project/
├── src/your_bot/
│   ├── main.py
│   ├── handlers.py
│   ├── keyboards.py
│   └── storage.py
├── data/
├── .env.example
└── setup.cfg
└── setup.py
```
+ `pre-commit` hooks.

## Спільні вимоги
- Python 3.10+ та `python-telegram-bot`;
- Зберігання токену у `.env` та створення `.env.example`;
- Дані читаються та зберігаються через JSON-обʼєкти;
- Неправильне введення команди показує підказку, а не зупиняє програму;
- Основні дії доступні через роботу `ReplyKeyboard`;
- Код розділений на зрозумілі файли та дотримується рекомендованої структури проекту;
- Функції мають type annotations і docstrings у Numpy-style форматі.


## Варіанти Telegram-ботів

### Варіант №1: Бот обліку витрат.

Бот допомагає користувачу записувати особисті витрати й бачити просту
статистику.

#### Обов’язковий функціонал

##### 1. Додавання витрати

Користувач вводить:

- суму;
- категорію;
- короткий опис.

Бот перевіряє суму й додає дату. Після збереження показує повідомлення про
успішне додавання.

Спосіб введення можна обрати самостійно:

- однією командою: `/add 120.50 Їжа Обід`;
- або покроково після натискання кнопки.

##### 2. Список витрат

Команда `/list` або кнопка показує:

- номер запису;
- суму;
- категорію;
- опис;
- дату.

Якщо список порожній, бот повідомляє про це.

##### 3. Статистика

Команда `/stats` показує:

- загальну суму всіх витрат;
- суму окремо для кожної категорії.

##### 4. Видалення

Користувач видаляє витрату за номером, наприклад `/delete 2`.
Якщо номера немає, бот нічого не видаляє й пояснює помилку.

##### 5. Окремі користувачі

Витрати зберігаються в `expenses.json` за Telegram ID. Один користувач не бачить
і не змінює записи іншого.

##### Підказки

- Telegram ID: `update.effective_user.id`;
- суму можна перетворити через `float()`;
- номер 1 у повідомленні відповідає індексу 0 у списку;
- для статистики за категоріями створи словник `category_totals`;
- поточний крок діалогу можна зберегти в `context.user_data`.

##### Додаткові завдання

Прості:

- команда очищення всіх витрат із підтвердженням;
- кнопки з готовими категоріями;
- кількість записів у статистиці.

Складніші:

- фільтр за категорією;
- витрати лише за сьогодні або за поточний місяць;
- встановлення місячного бюджету та попередження про перевищення.

### Варіант №2: Бот-вікторина

Бот завантажує запитання з JSON, проводить гру та зберігає найкращий результат.

#### Обов’язковий функціонал

##### 1. Початок гри

Команда `/quiz` або кнопка:

- завантажує `questions.json`;
- обирає п’ять випадкових запитань;
- встановлює початковий бал 0;
- показує перше запитання.

Повторний запуск `/quiz` починає нову гру.

##### 2. Запитання й відповіді

Для кожного запитання бот показує:

- номер, наприклад `Запитання 2/5`;
- текст запитання;
- варіанти відповідей кнопками.

Бот приймає лише один із запропонованих варіантів.

##### 3. Перевірка відповіді

Після кожної відповіді бот:

- повідомляє, правильна вона чи ні;
- показує правильний варіант;
- показує пояснення з JSON;
- переходить до наступного запитання.

##### 4. Завершення гри

Після п’ятого запитання бот показує фінальний бал, наприклад `4/5`, і повертає
головне меню. Команда `/stop` дозволяє завершити гру раніше.

##### 5. Результати

Команда `/result` показує:

- кількість завершених ігор;
- найкращий результат користувача.

Результати зберігаються в `quiz_results.json` окремо за Telegram ID.

##### Підказки

- випадковий вибір: `random.sample()`;
- список питань, поточний номер і бал зберігай у `context.user_data`;
- правильна відповідь знаходиться в полі `answer`;
- після відповіді збільшуй `question_index` на 1;
- гра завершена, коли індекс дорівнює довжині списку.

##### Додаткові завдання

Прості:

- показувати відсоток правильних відповідей;
- додати більше запитань;
- різні повідомлення для слабкого й високого результату.

Складніші:

- вибір теми або рівня складності;
- перемішування варіантів відповідей;
- історія останніх результатів;
- спільна таблиця лідерів.

### Варіант №3: Бот курсів валют

Бот читає локальні курси з JSON, показує їх і конвертує суми.

#### Обов’язковий функціонал

##### 1. Перегляд курсів

Команда `/rates` або кнопка показує:

- дату курсів;
- базову валюту;
- перелік доступних валют і значень.

Якщо файл порожній або відсутній, бот показує зрозуміле повідомлення.

##### 2. Конвертація

Користувач вводить суму та два коди, наприклад:

```text
/convert 100 USD UAH
```

Можна також зробити покрокове введення після натискання кнопки.

Бот перевіряє:

- чи сума є додатним числом;
- чи складаються коди з трьох літер;
- чи є обидві валюти в `rates.json`.

##### 3. Формула

Усі значення в JSON задані відносно однієї базової валюти:

```text
result = amount / rates[from_currency] * rates[to_currency]
```

Результат потрібно округлити до двох знаків.

##### 4. Історія

Після успішної конвертації бот зберігає:

- початкову суму й валюту;
- отриману суму й валюту;
- дату та час операції.

Команда `/history` показує останні п’ять операцій поточного користувача.
Історії різних Telegram ID не змішуються.

##### Підказки

- коди валют перетворюй через `.upper()`;
- список доступних валют — це ключі словника `rates`;
- результат округлюй через `round(result, 2)`;
- дату можна отримати через `datetime.now()`;
- у JSON можна залишати лише останні 10 операцій.

##### Додаткові завдання

Прості:

- кнопки для популярних валют;
- команда очищення історії;
- повтор останньої конвертації.

Складніші:

- отримання актуальних курсів із Frankfurter REST API;
- вибір базової валюти;
- показ дати останнього оновлення;
- автоматичне оновлення `rates.json` через API.
